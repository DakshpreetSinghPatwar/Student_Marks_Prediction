# Student Marks Prediction

## Project Description
This project predicts a student's marks using Machine Learning.

The model uses:
- Study Hours
- Previous Exam Marks
- Attendance Percentage

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Linear Regression

## Files
- model.py - Main machine learning program
- students.csv - Student dataset
- README.md - Project documentation

## How to Run

1. Open the project in VS Code.
2. Activate the virtual environment if required.
3. Install the required libraries:

pip install pandas scikit-learn matplotlib

4. Run the program:

python model.py

5. Enter:
   - Study hours
   - Previous exam marks
   - Attendance percentage

The program then predicts the student's marks.

## Machine Learning Algorithm

Linear Regression is used to learn the relationship between the input features and student marks.

## Conclusion

The project demonstrates how machine learning can be used to predict student marks based on academic factors.
